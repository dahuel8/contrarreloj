# Contrarreloj · Edición Cumpleañito 🎉

Juego multijugador en tiempo real. El organizador crea una sala y comparte el código de 4 letras con los demás jugadores.

## Deploy en Railway

1. Subí esta carpeta a un repositorio de GitHub
2. En Railway, creá un nuevo proyecto → "Deploy from GitHub repo"
3. Seleccioná el repositorio
4. Railway detecta automáticamente que es Node.js y lo deploya

## Desarrollo local

```bash
npm install
npm start
```

Abrí http://localhost:3000
